How I work

The same five steps on every project.

  1. Collect

    Pull raw data from sheets, ERP exports and databases.

  2. Clean

    Remove duplicates, fix types and labels, and reconcile totals against the source.

  3. Model

    Define each metric once in SQL or DAX so every table agrees.

  4. Visualize

    Build views that each answer one question.

  5. Automate

    Script the refresh so the report updates without manual work.
